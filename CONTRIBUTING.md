# Contributing to dotclaude

Thanks for your interest. This is a small personal project, so please keep changes focused.

## Reporting bugs and asking for features

Open an [issue](https://github.com/abhichandra21/dotclaude/issues).
For bugs, include what you did, what you expected, what happened instead, and your OS and version.

For security problems, do not open a public issue. See [SECURITY.md](SECURITY.md).

## Making changes

1. Open an issue first for anything larger than a small fix, so we can agree on the approach.
2. Fork the repo and create a branch for your change.
3. Make the change and run the tests (see below).
4. Open a pull request that explains what changed and why.

## Development

This repo is a set of config files, so there is nothing to build.
Follow the Setup section in the [README](README.md) to try your change in your own `~/.claude`.
Never commit real API keys, profile names, or other personal values; use placeholders like `<YOUR_API_KEY>`.
